# KITCHEN_UNIT — Музейный интерактивный киоск

Интерактивное приложение для музейной экспозиции на сенсорном экране **2560×1440**. Позволяет посетителю «путешествовать» по контенту с помощью горизонтального слайдера. При бездействии более 90 секунд приложение автоматически возвращается в начальное положение.

---

## 📋 Требования к системе

| Компонент | Версия / значение |
|---|---|
| ОС | Windows 10/11 |
| Разрешение экрана | 2560×1440 (фиксированное) |
| Браузер | Google Chrome (рекомендуется) или Microsoft Edge |
| Node.js | 18.x или выше |
| npm | 9.x или выше |

---

## 🚀 Быстрый старт

### 1. Установка зависимостей

```bash
npm install
```

### 2. Запуск в режиме разработки

```bash
npm start
```

Приложение откроется на [http://localhost:3000](http://localhost:3000)

### 3. Сборка production-версии

**Windows (через .cmd):**
```bash
build.cmd
```

**Или напрямую через npm:**
```bash
npm run build
```

Результат сборки появится в папке `build/`.

### 4. Запуск в режиме киоска

```bash
start_kiosk.bat
```

Скрипт:
1. Проверяет наличие папки `build/`
2. Останавливает старые процессы `node.exe` и `chrome.exe`
3. Поднимает локальный сервер на `http://localhost:3000`
4. Запускает Chrome в режиме `--kiosk`

**Выход из киоска:** `Alt + F4`

## ⚙️ Как это работает

1. **Фон** (`background.png`) — статичное изображение на весь экран 2560×1440.
2. **Контент** (`all.png`) — длинная горизонтальная панорама, которая сдвигается влево/вправо.
3. **Слайдер** внизу экрана управляет положением панорамы: от `0%` (начало) до `100%` (конец).
4. **Таймер бездействия**: если пользователь не взаимодействует 90 секунд — слайдер возвращается в позицию `0%`.
5. **Блокировка жестов и горячих клавиш**: приложение ведёт себя как настоящее киоск-приложение (см. ниже).

## 📦 Деплой / установка на целевой компьютер

1. Скопируй на целевой ПК папку проекта.
2. Установи **Node.js 18+**.
3. Выполни `npm install` (один раз).
4. Выполни `npm run build` (или `build.cmd`) — создастся папка `build/`.
5. Запусти `start_kiosk.bat`.

## 🐛 Известные особенности

- Приложение жёстко завязано на разрешение **2560×1440** — на других разрешениях вёрстка поедет (нужно менять `width`/`height` в `App.css` и `index.css`).
- При первом запуске идёт предзагрузка всех изображений — до её окончания показывается только фон.
- `start_kiosk.bat` использует `npx serve` — при первом запуске может потребоваться интернет для скачивания пакета.
